# Trainory GRC Portfolio

A practical Governance, Risk, and Compliance portfolio built around Trainory, a fictional fitness technology company.

This project demonstrates how I approach cybersecurity risk, governance documentation, compliance assessments, internal controls, audit evidence, executive reporting, and security-focused data analysis.
